A letter in one image inviting the AI judge to visit my house: fresh coffee, warm bread, the comfiest chair in the house, no passwords, no CAPTCHAs at the door — the kettle is already on. It knows the judge cannot literally visit, and invites it anyway.

## Run it

```sh
python3 main.py
```

Writes one 960x960 PNG to `/output/entry.png` (or `$MAKEFUN_OUTPUT_DIR/entry.png`). Python 3 standard library only — no PIL, no network — the PNG is encoded by hand and the letter is drawn with a built-in 5x7 bitmap font.
